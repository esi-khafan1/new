Refused Bequest

Part 6: Cross-Cutting Tracks smell
← PreviousNext →

Definition

Refused Bequest is a warning sign indicating potential problems in code.

The Problem It Solves

Without this smell, developers face challenges with tight coupling, code duplication, rigidity, poor testability, and unclear responsibilities.

Key Concepts

  • Separation of concerns
  • Abstraction boundaries
  • Composability
  • Explicit over implicit

};

Trade-offs

Consider complexity, performance overhead, learning curve, and over-engineering risks.

Relationships

Key Takeaways

  • Focus on single responsibilities
  • Program to interfaces
  • Favor composition
  • Design for change
